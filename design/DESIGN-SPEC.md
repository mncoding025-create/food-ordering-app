# DESIGN-SPEC — Food Ordering

> ถอดจากไฟล์ดีไซน์จริง (Claude Design) ใช้เป็นแหล่งอ้างอิงหลักของหน้าตา UI ตลอดงาน
> ส่วนท้ายไฟล์ "ภาคผนวก: การตัดสินใจเพิ่มเติม" คือจุดที่สเปกไม่ครอบคลุม ซึ่งอนุมัติพร้อมแผนแล้ว

## ทั่วไป
- พื้นหลังหน้า cream #FFF8F0, ตัวอักษร ink #1C1917, ข้อความรองใช้ #57534E, ฟอนต์ Noto Sans Thai 18px/1.6
- Header ทุกหน้า: พื้นขาว เส้นล่าง #EADFD0, ความกว้างสูงสุด 1100–1360 ตามหน้า, padding 12px 24px
- โลโก้: กล่องสี่เหลี่ยมมน 44px พื้นส้ม #F97316 ไอคอนสี ink (ไอคอนชามอาหารมีไอ เช่น Soup ใน lucide) + ข้อความ "Food Ordering" 24px/800
- Header ฝั่งลูกค้า: โลโก้ + ปุ่ม outline "ติดตามออเดอร์" (ไอคอน Search, สูง 48px, border 2px #D6C9B8, มุม 14px)
- Header หน้าติดตาม: โลโก้ + ปุ่ม outline "กลับไปเมนู" (ไอคอน ChevronLeft)
- Header ฝั่งร้านค้า: กล่องโลโก้พื้น ink #1C1917 ไอคอน Store สีขาว + "Food Ordering · หน้าร้านค้า" (ส่วนหลังสี muted) + ป้ายวงรี "อัปเดตอัตโนมัติ" (พื้น #F5F0E8, ไอคอน RefreshCw)

## หน้าแรก /
- Hero กึ่งกลาง: h1 44px/800 "หิวแล้วใช่ไหม? สั่งอาหารได้ใน 3 ขั้นตอน", คำอธิบาย 20px muted "เลือกเมนูที่ชอบ ใส่ชื่อ แล้วกดสั่ง — ติดตามสถานะได้ทันทีโดยไม่ต้องสมัครสมาชิก"
- การ์ดใหญ่ 2 ใบ (grid auto-fit min 300px, gap 24, padding 32, มุม 24, เงา panel):
  ก) ขอบ 2px ส้ม, กล่องไอคอน 72px มุม 20 พื้น brand-tint ไอคอน ShoppingCart สี brand-dark, h2 30px/700 "ลูกค้า: สั่งอาหาร", ข้อความ "ดูเมนู เลือกอาหาร ใส่ตะกร้า แล้วยืนยันออเดอร์ได้เลย", ปุ่มส้มสูง 56 "เริ่มสั่งอาหาร" + ลูกศร -> /menu
  ข) ขอบ 2px #D6C9B8, กล่องไอคอนพื้น #F5F0E8 ไอคอน Store, "ร้านค้า: จัดการออเดอร์", "ดูออเดอร์ที่เข้ามาและเปลี่ยนสถานะทีละขั้นได้ในแวบเดียว", ปุ่ม outline ink สูง 56 "เข้าสู่หน้าร้านค้า" + ลูกศร -> /vendor
- การ์ดขาว "ใช้งานง่ายแค่ 3 ขั้นตอน" (h2 24px กึ่งกลาง): 3 ขั้น วงกลมส้ม 52px เลข 1-3 สี ink + หัวข้อ 22px/700 + คำอธิบาย 17px muted มีลูกศรเทาคั่น: 1 เลือกเมนู "เลือกอาหารและเครื่องดื่มที่อยากกิน ใส่ลงตะกร้า" / 2 ยืนยันออเดอร์ "ตรวจรายการ ใส่ชื่อ แล้วกด “ยืนยันสั่งอาหาร”" / 3 ติดตามสถานะ "ดูได้ว่าร้านกำลังทำถึงขั้นไหน อัปเดตให้อัตโนมัติ"
- Footer เล็ก muted: "Food Ordering · โปรเจกต์ระบบสั่งอาหารออนไลน์" (ตัดข้อความ "ข้อมูลในหน้านี้เป็นตัวอย่าง" ออก)

## หน้าเมนู /menu (จอคอม)
- โครง: คอนเทนเนอร์กว้างสูงสุด 1280 flex-wrap; ซ้ายคือ main เมนู, ขวาคือแผงตะกร้า (กว้าง 360–420, sticky top-16)
- หัวเรื่อง h1 36px/800 "เมนูวันนี้" + "เลือกเมนูที่ชอบ แล้วกด “เพิ่มลงตะกร้า”"
- Chip หมวด (ทั้งหมด/อาหารจานเดียว/ก๋วยเตี๋ยว/เครื่องดื่ม/ของหวาน): วงรี สูง 48, padding 0 22px, border 2px; ที่เลือก = พื้น #FFEDD5 ขอบส้ม + ไอคอน Check; ที่ไม่เลือก = พื้นขาว ขอบ #D6C9B8; aria-pressed
- กริดการ์ดอาหาร: auto-fill minmax(230px,1fr) gap 20; การ์ดขาว มุม 20 padding 12 เงา card ขอบ 2px (โปร่งใส; เป็นส้มเมื่ออยู่ในตะกร้า)
  - พื้นที่รูป aspect 4/3 มุม 14 พื้นสีตามหมวด + ไอคอนหมวด 64px: อาหารจานเดียว พื้น #FFEDD5 ไอคอน #9A3412 / ก๋วยเตี๋ยว #FEF3C7 #92400E / เครื่องดื่ม #E0F2FE #075985 / ของหวาน #FCE7F3 #9D174D ; ถ้ามี imageUrl ให้แสดงรูปเต็มกรอบแทน (fallback ไอคอน)
  - ถ้าอยู่ในตะกร้า: ป้ายมุมซ้ายบน พื้น ink ตัวอักษรขาว มีไอคอน Check "ในตะกร้าแล้ว"
  - ชื่อ 20px/700, คำอธิบาย 15px muted (2 บรรทัด), ราคา "฿60" 22px/800 สี brand-dark #C2410C
  - ยังไม่อยู่ในตะกร้า: ปุ่มส้มสูง 48 "เพิ่มลงตะกร้า" (ไอคอน Plus); อยู่แล้ว: ตัวปรับจำนวน − (ปุ่ม 48 ขอบ 2px ink) จำนวน 22px/800 + (ปุ่ม 48 พื้นส้ม) พร้อม aria-label "ลดจำนวน/เพิ่มจำนวน <ชื่อเมนู>"
- แผงตะกร้า (aside): พื้นขาว มุม 24 padding 24 เงา panel ขอบ #EADFD0
  - หัวแผง: ไอคอนตะกร้า + "ตะกร้าของคุณ" 24px/800 + ป้าย "N รายการ" (พื้น #FFEDD5 ตัวอักษร #9A3412)
  - ว่าง: กล่องเส้นประ 2px #D6C9B8 ไอคอนตะกร้าเทา "ตะกร้ายังว่างอยู่" 20px/700 + "เลือกเมนูที่ชอบ แล้วกด “เพิ่มลงตะกร้า”"
  - แต่ละรายการ: ชื่อ 18px/600 + ยอดรายการ 18px/700, ตัวปรับจำนวน (ปุ่ม 44) และปุ่มข้อความ "ลบ" สีแดง #B91C1C + ไอคอน Trash2 (aria-label "ลบ <ชื่อ> ออกจากตะกร้า")
  - "ยอดรวม" 20px/600 และตัวเลข 32px/800 สี brand-dark
  - ช่อง "ชื่อลูกค้า" (label 17px/700, input สูง 52, มุม 14, ขอบ 2px #A8A29E, placeholder "เช่น คุณสมชาย") ; error: ขอบ #DC2626 + role="alert" ไอคอน AlertCircle สีแดง ข้อความ "กรุณากรอกชื่อก่อนยืนยันออเดอร์" (ข้อความ error อื่นของ service แสดงในรูปแบบเดียวกัน)
  - ปุ่ม "ยืนยันสั่งอาหาร" สูง 56 ส้ม ตัวอักษร 20px/800 ไอคอน Check; ระหว่างส่ง: disabled พื้น #FDBA74 cursor wait ไอคอนหมุน "กำลังส่งออเดอร์…"
  - เมื่อสำเร็จ: ล้างตะกร้าแล้ว redirect ไป /track?no=<เลขออเดอร์> (ไม่ต้องทำกล่องสำเร็จในตะกร้า)
- มือถือ: header กระชับ (โลโก้ 40px, ชื่อ 20px), chip เลื่อนแนวนอน, การ์ดเมนู 1–2 คอลัมน์, ด้านล่างมีแถบสรุป fixed "ตะกร้า N รายการ · ฿ยอดรวม" กดเปิด bottom sheet: ฉากหลัง rgba(28,25,23,.55), แผ่นพื้นขาวมุมบน 24 เงา sheet, แถบจับ 44x5 สี #D6C9B8, หัว "ตะกร้าของคุณ" + ป้ายจำนวน + ปุ่มปิด 48px (พื้น #F5F0E8, ไอคอน X, aria-label "ปิดตะกร้า"), เนื้อหาเหมือนแผงตะกร้า (ตัวปรับจำนวน 44px, ยอดรวม 30px, ช่องชื่อ, ปุ่มยืนยัน) role="dialog" aria-modal ปิดด้วย Esc/ฉากหลัง

## หน้าติดตามออเดอร์ /track (กว้างสูงสุด 1100)
- การ์ดค้นหา (ขาว มุม 20 ขอบ #EADFD0 padding 16x20): label "ค้นหาเลขออเดอร์" 16px/700, input สูง 52 + ปุ่มส้ม "ค้นหา" (ไอคอน Search)
- การ์ดหลัก (มุม 24 padding 32 เงา panel) 2 ส่วนข้างกัน: ซ้ายคือการ์ดหลัก, ขวาคือการ์ด "รายการอาหาร" (กว้างสูงสุด 420 รายการ ชื่อ × จำนวน + ยอดรายการ, ยอดรวม 32px/800 สี brand-dark); มือถือเรียงเป็นแนวตั้ง
- ในการ์ดหลัก: "เลขออเดอร์ของคุณ" 17px muted, เลขออเดอร์ 72px/800 (มือถือ 52px), ชื่อลูกค้า 20px/600, "สั่งเมื่อ HH:MM น." 16px muted; ป้ายวงรีขวาบน "อัปเดตอัตโนมัติ · ล่าสุด HH:MM น." (พื้น #F5F0E8 ไอคอน RefreshCw)
- Stepper 4 ขั้น (ol, aria-label "ขั้นตอนของออเดอร์"): รอดำเนินการ(Clock) → กำลังทำ(ChefHat) → พร้อมรับ(CircleCheck) → เสร็จสิ้น(Package)
  - ขั้นที่ผ่านแล้ว: วงกลม 64px พื้น #44403C ไอคอน Check สีขาว ป้าย "ผ่านแล้ว" ; ขั้นปัจจุบัน: วงกลม 80px พื้นสี ink ของสถานะ ไอคอนสีขาว มีวงแหวน 6px สี bg ของสถานะ ตัวอักษร 800 และป้าย "ตอนนี้" (aria-current="step"); ขั้นที่ยังไม่ถึง: วงกลม 64px พื้นขาว ขอบเส้นประ 3px #A8A29E ไอคอนเทา
  - เส้นเชื่อม 4px: ทึบ #44403C ช่วงที่ผ่านแล้ว, เส้นประ #A8A29E ช่วงที่ยังไม่ถึง
- กล่องข้อความสถานะ (role="status", มุม 20, padding 20x24, พื้น/ขอบ/ตัวอักษรตามสีสถานะ): ไอคอนในสี่เหลี่ยมมน 56px พื้น ink ของสถานะ ไอคอนขาว + หัวข้อ 26px/800 + คำอธิบาย 18px
  - PENDING: "ร้านได้รับออเดอร์แล้ว" / "กำลังรอคิวปรุงอาหาร หน้านี้จะอัปเดตให้อัตโนมัติ"
  - PREPARING: "ร้านกำลังปรุงอาหารของคุณ" / "รอสักครู่ หน้านี้จะอัปเดตให้อัตโนมัติเมื่อสถานะเปลี่ยน"
  - READY: "อาหารของคุณพร้อมแล้ว!" / "มารับที่หน้าร้านได้เลย แจ้งเลขออเดอร์ <เลข> กับพนักงาน"
  - COMPLETED: "ออเดอร์เสร็จสิ้นแล้ว" / "ขอบคุณที่ใช้บริการ"
- ไม่พบเลขออเดอร์ (กว้างสูงสุด 760): ช่องค้นหาเป็นสถานะผิด (พื้น #FEF2F2 ขอบ #DC2626 aria-invalid) และการ์ด role="alert" ขอบ 2px #FCA5A5 มุม 24 กึ่งกลาง: วงกลม 80px พื้น #FEE2E2 ไอคอน SearchX 44 สีแดง, h1 32px/800 "ไม่พบเลขออเดอร์ <เลขที่ค้น>", "ลองตรวจสอบว่าพิมพ์เลขถูกต้อง เลขออเดอร์จะเป็นรูปแบบ FO-0001 (FO ตามด้วยเลข 4 หลัก)", ปุ่ม "ลองค้นหาใหม่" (ส้ม) และ "กลับไปสั่งอาหาร" (outline ink)

## หน้าร้านค้า /vendor (คอนเทนเนอร์ 1240–1360)
- หัวเรื่อง h1 36px/800 "จัดการออเดอร์" + "· ทั้งหมด N ออเดอร์" 20px/600 muted ; คำอธิบายใต้หัว "วันนี้ · <วันที่ภาษาไทย พ.ศ. จากเวลาจริง> · ออเดอร์เลื่อนไปคอลัมน์ถัดไปเมื่อกดปุ่มเปลี่ยนสถานะ"
- ตัวสลับมุมมองแบบ segmented (ขอบ 2px ink มุม 14): "การ์ด + ตัวกรอง" | "Kanban 4 คอลัมน์" ; ตัวที่เลือก = พื้น ink ตัวอักษรขาว มี Check ; ค่าเริ่มต้น Kanban
- สีสถานะ (bg / ตัวอักษร / ขอบ): PENDING #FEF3C7/#92400E/#F59E0B, PREPARING #DBEAFE/#1E40AF/#3B82F6, READY #DCFCE7/#166534/#22C55E, COMPLETED #E7E5E4/#44403C/#A8A29E
- Kanban: grid auto-fit minmax(260px,1fr) gap 16; คอลัมน์ มุม 20 padding 12 พื้นสี bg ของสถานะ ขอบบน 8px สีขอบสถานะ; หัวคอลัมน์ไอคอน+ชื่อสถานะ 22px/800 สี ink + วงกลมจำนวน 44px พื้นขาวขอบสีสถานะ ตัวเลข 24px/800; การ์ดออเดอร์ขาว มุม 16 padding 16 เงา: เลขออเดอร์ 24px/800 + เวลา "HH:MM น." มุมขวา, ชื่อลูกค้า 18px/600, รายการ "ชื่อ × จำนวน" (เส้นคั่นบน-ล่าง), "ยอดรวม" + 24px/800 brand-dark, ปุ่มส้มสูง 48 "เปลี่ยนเป็น: <สถานะถัดไป>" + ลูกศร ; คอลัมน์เสร็จสิ้นไม่มีปุ่ม แสดงกล่อง "เสร็จสมบูรณ์" (พื้น #F5F0E8 ไอคอน Check)
- มุมมองการ์ด + ตัวกรอง: การ์ดสรุป 5 ใบ (ทั้งหมด + 4 สถานะ) grid auto-fit minmax(190px,1fr) gap 16 เป็นปุ่ม aria-pressed มุม 20 padding 16: ไอคอน+ชื่อ 18px/700, ตัวเลข 52px/800, ข้อความ "กำลังแสดง" + Check เมื่อเลือก; เลือกแล้ว = ขอบ 4px สีขอบสถานะ พื้นสี bg สถานะ (ทั้งหมด: พื้น #F5F0E8 ขอบ ink); ยังไม่เลือก = พื้นขาว ขอบ 2px #EADFD0
  - ใต้นั้นเป็นการ์ดออเดอร์ grid auto-fill minmax(320px,1fr) gap 20: มุม 20 padding 20 ขอบบน 6px สีสถานะ; เลขออเดอร์ 26px/800, ชื่อ 18px/600, เวลา; ป้ายสถานะวงรี (ไอคอน+ข้อความ พื้น/ตัวอักษร/ขอบ 2px ตามสถานะ) ขวาบน; รายการ, ยอดรวม 26px/800; ปุ่มส้มสูง 52 "เปลี่ยนเป็น: <ถัดไป>" หรือกล่อง "ออเดอร์เสร็จสมบูรณ์" ; ไม่มีออเดอร์ในตัวกรอง: กล่องเส้นประ "ไม่มีออเดอร์ในสถานะนี้"
- ไม่มีออเดอร์เลย: empty state กล่องเส้นประกึ่งกลาง ไอคอน Inbox "ยังไม่มีออเดอร์" + "ลองสั่งจากหน้าสั่งอาหาร" (ลิงก์ไป /menu)
- ปุ่มเล็ก "ล้างข้อมูลทดสอบ" (window.confirm) ไว้ในหัวหน้า ไม่เด่น (นอกเหนือจากดีไซน์ ไว้ใช้ซ้อม demo เท่านั้น)

## ความเข้าถึง (ใช้ทุกหน้า)
ใช้ `<button>`/`<a>`/`<input>` + `<label>` จริง, aria-label บนปุ่มไอคอน, ไอคอนตกแต่ง aria-hidden, คอนทราสต์ตามค่าสีด้านบน, ปุ่ม/ช่องกรอกสูงอย่างน้อย 44–48px

## ภาคผนวก: การตัดสินใจเพิ่มเติม (อนุมัติพร้อมแผน 2026-11-16)
1. ฟิลด์ `imageEmoji` คงไว้ในข้อมูล (เผื่อทำ seed) แต่ไม่แสดงใน UI
2. ไอคอนหมวด: อาหารจานเดียว `UtensilsCrossed`, ก๋วยเตี๋ยว `Soup`, เครื่องดื่ม `CupSoda`, ของหวาน `IceCreamCone`; โลโก้ `Soup`; AlertCircle → `CircleAlert`; ไอคอนหมุน `LoaderCircle`
3. หน้าแรกใช้ header ฝั่งลูกค้า; โลโก้ทุกหน้าลิงก์กลับ `/`
4. มือถือ /menu: header กระชับ, chip เลื่อนแนวนอน, กริด 2 คอลัมน์, แถบตะกร้าล่างแสดงเฉพาะเมื่อมีของ
5. มือถือ /track: เลขออเดอร์ 52px, การ์ดรายการอยู่ใต้การ์ดหลัก, stepper แนวตั้ง (<640px) วงกลม 48/60px
6. /track ไม่มี `?no=`: การ์ดค้นหา + chip เลขออเดอร์ล่าสุดของเครื่องนี้ (≤5); ช่องค้นหา normalize "7"/"fo7" → FO-0007
7. "ล่าสุด HH:MM น." = เวลาที่โหลดข้อมูลสำเร็จครั้งล่าสุด
8. /vendor: ปุ่มรีเฟรชข้าง ViewToggle; Kanban บนมือถือเรียงแนวตั้ง; แสดง skeleton จนกว่าจะอ่านค่ามุมมองเสร็จ
9. Loading: skeleton พื้น #F5F0E8 + animate-pulse; service หน่วง ~300ms
10. Error จาก service แสดงแบบเดียวกับ error ช่องชื่อ (CircleAlert แดง, role="alert")
